# Sales and Profit Calculator

My second Python project: a simple command-line calculator to check profit or loss from selling a product.

## Features
- Takes buying price, selling price, and quantity
- Calculates total profit or loss
- Shows whether the sale made a profit, a loss, or broke even
- Rejects negative values

## How to Run
1. Install Python 3.
2. Download `sales_profit.py`.
3. Open a terminal in the file's folder.
4. Run:

```bash
python sales_profit.py
```

## Example
```text
---- Sales & Profit Calculator ----
Enter the buy price: 50
Enter the sell price: 80
Enter the quantity: 10
Profit: Rs. 300.00
```

## Formula
```text
Profit = (Selling Price - Buying Price) × Quantity
```

A negative result means a loss.
